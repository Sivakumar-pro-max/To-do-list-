# To-Do List Application

##  About the Project
This is a simple **To-Do List Application** developed using Python. It helps users manage their daily tasks through a menu-driven program. Users can add new tasks, view their existing tasks, and delete tasks when they are completed or no longer needed.

## Features
- **Add Task:** Add new tasks to the to-do list.
- **View Tasks:** Display all tasks with their corresponding numbers.
- **Delete Task:** Remove a task by entering its task number.
- **Exit:** Exit the application.

##  Technologies Used
- Python 3
- Built-in Python functions and modules

##  How to Run

1. Clone this repository:
   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project folder:
   ```bash
   cd todo-list
   ```

3. Run the Python program:
   ```bash
   python todo.py
   ```
